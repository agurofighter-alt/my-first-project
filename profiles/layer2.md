# profiles/layer2.md — レイヤー2壺(事業納品物の蠱毒)(v1.4/GEN-6・STL-8・TNG-2)

## 移送プロトコル(レイヤー1勝者の入場)
移送記録として以下を**セットで**持ち込む(欠けたら移送不可):
1. 勝者の蟲(3要素+課メモ全文)
2. **安全帳票**——開きフラグ(要人間確認)が残る蟲は**移送できない**(人間がクローズしてから)
3. 元壺のキルログ要約(毒。壺師が task 設計に翻訳して使う——翻訳の合法性は§3どおり)
4. 元壺の shared_context 版番号と舌の記録(逐語)

## この壺の題材
「その事業の納品物」(コピー・LP・価格表・仕様・試作)。成文法が薄いので:
- 物理/校則KILL≈0 を前提に、**帯域N・★基準・目安枠を Stage0 で必ず数値宣言**する。
- 圧縮は 枠の法→乱数圧縮の法(§8)で回す。審美圧縮は最後まで舌のみ。

## 専門家毒見(Stage3ゲート)の意味論
- 専門家は**[未検証]タグを[検証済み]/[誤り]に変える装置**。順位・推奨は出さない(出したら記録から落とす)。
- [誤り]認定は成文抵触KILLの根拠になる(これは閾値でなく検証)。

## 市場信号の位置
- 市場実測(テスト販売・計測)は**壺の外**で行い、実測値だけが客観記録として入る。
- 機械は実測の**整理まで**(§5)。推奨・順位・「勝ち筋」の語りは禁止。
- 最終エンドは舌。

## 死因カテゴリ表(雛形)
| カテゴリ | 定義 |

| 与件 | 予算・納期・法規(表示義務等)の超過 |
