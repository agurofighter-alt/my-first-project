# profiles/ — 壺クラスプロファイル(v1.4/GEN-1)

憲法(rules.md)は不変核とスロットだけを持つ。**壺クラス固有の語彙はここが定義**し、Stage0で1つ選んで宣言する。プロファイルが埋めるスロット:

| スロット | 内容 |
|---|---|
| 死因カテゴリ表 | 選択式死因の一覧と各定義 |
| 「実質同じ」の定義 | 重複判定の領域語 |
| 課の職掌対応 | からくり/関所/算盤/橋渡し(/化粧)が何を見るか |
| 安全帳票の対象領域 | 機械が断定せず要人間確認に上げる領域語 |
| 出典の扱い | 壺内図書の要否・構成 |
| 客観フィルタの実体 | 形式チェック or test/lint/ビルド 等 |

- 既存: `kikaku.md`(企画・イベント壺)/ `code.md`(コード壺)/ `senmon.md`(専門領域壺)/ `layer2.md`(レイヤー2=事業納品物壺)
- 新クラスが必要ならプロファイルを**起案**し、舌の批准を受けてから使う(§15)。
