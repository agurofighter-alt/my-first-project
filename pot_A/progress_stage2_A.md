## Stage2-A

### 1. 駄菓子屋台(昭和レトロ再現)
深化仕組み: 教室入口を「暖簾+木箱陳列」でゲート化し、客は棚(机を重ねた陳列台)を回遊して欲しい商品を指差し注文、店番役が個包装のまま商品を取り出して手渡す一方通行の動線とする。核ギミックは天秤式量り売りの"実演"だが、実際に計量するのは包装済み商品の受け渡し前パフォーマンスのみとし、開封・小分けは一切行わない。会計はレトロ電卓/そろばんでの計算演出+別テーブルでの食券制とし、現金の直接授受場面を絞る。所要時間は客ごとに固定でなく回遊式のため滞在は概ね2〜4分、補充役1名・店番2名・会計1名の計4名体制で運用する。

関所: 条件付きpass(食品衛生上、販売は全品未開封の工場包装品に限定し量り売り演出は空計量のみで実施すること/瓶ジュースは割れ物リスクのためPET・缶の"レトロ意匠"品に置換すること/食品・飲料販売は学校の実施要項上、事前の委員会承認と教員立ち会いが別途必要) / 算盤: pass(仕入原価は個包装駄菓子相場で1個10〜50円程度と低額、通常の学級予算内で仕入可能。回遊・即売方式のため滞留が少なくレジ回転のみが律速となり、概算20〜40人/時を処理可能) / 近傍変種: 対面受け渡しを「食券先売り+商品はレジ後方から店番が渡すだけ」の分離動線にし、現金授受を会計係1名に集約することで衛生条件と現金管理条件を同時に軽くできる。

### 2. お化け屋敷(王道)
深化仕組み: 教室を段ボール+黒布で蛇行1本道に区切り、入口係が前組の進行位置を確認してから3〜4人組を約4〜5分間隔で送り出す。核ギミックは通路中2〜3箇所に配置した驚かせ役による接近トリガー型の脅かしで、組が特定ポイント通過時に手動合図で位置を把握して飛び出し、スピーカーによる環境音(軋み・悲鳴)を併用して単調さを避ける。出口は入口と別動線にして退出客と入場待機列が交錯しない設計とし、入口係・驚かせ役3名・出口係・巡回安全係の計6名で運用する。

関所: 条件付きpass(段ボール・黒布は防炎処理品または防炎スプレー処理必須/通路途中に緊急時引き剥がし可能な非常口区画を1〜2箇所設置/完全暗転は避け足元最低限の誘導灯・蓄光表示を常設/入口に「大きな音・急な接触あり、心臓疾患等は要注意」の掲示を設置) / 算盤: pass(材料費は段ボール・黒布中心で低コスト、防炎品購入分のみ増額するが学級予算内。3〜4人組を4〜5分間隔で送り出せるため概算36〜60人/時を処理可能で回転効率は良好) / 近傍変種: なし(関所条件への対応のみで運用可能なため追加の緩和策は不要)。

### 3. 暗幕迷宮ウォーク「視聴覚室、戻れません」
深化仕組み: 視聴覚室全体を黒暗幕で仕切り、入退室に光を遮る二重暗幕(ライトロック)を設け、蓄光テープのみを頼りに1〜2名単位で蛇行路を進む一方通行構造とする。核ギミックは姿を見せる演者を置かず、隠れたスピーカーと物陰の演者による方向音(背後の足音・耳元の息づかい・ささやき)のみで「気配」を演出し、視覚情報を遮断した状態での聴覚トリガーに絞る。安全確保のため常時1名が暗視カメラ/覗き窓で室内を監視し、異常時は即座に照明を点灯できる非常灯連動スイッチを併設、監視・音響操作・演者2名・入退室誘導の計5〜6名で運用する。

関所: 条件付きpass(暗幕は防炎認定品必須/火災報知連動または手動即時点灯できる非常照明を必ず設置し「完全暗転」は演出上の瞬間にとどめ避難誘導灯機能を損なわないこと/一方通行のゲート・仕切りは内側から緊急時に強制開放できる構造とすること/室内を常時監視し異常時に即応できる体制を必須とする) / 算盤: fail(理由: 安全確保のため1〜2名までの少人数制限+暗闇での低速進行+組間の安全確認バッファが必須となり、回転が概算20〜25人/時にとどまる。5〜6名のスタッフを要する運用規模に対して処理人数が他3案より明確に少なく、稼働時間内で捌ける人数の伸びが構造的に頭打ちになる) / 近傍変種: 経路を短縮再設計して体験時間を3分固定化した上で、室内を左右2系統の独立暗幕導線に分割し2組を同時運用することで、回転を概算倍増(40〜50人/時程度)まで引き上げられる。

### 4. 呪いの写真館「もう一人写っている」
深化仕組み: 撮影スペースの背景側を意図的に薄暗く保ち、白塗りの演者を背景の物陰(装飾パネルの陰など)に客の視界に入りにくい定位置で静止させ、客はその存在にほぼ気付かないまま通常のポーズで撮影に臨む。核ギミックはフラッシュ撮影特有の「暗所では見えにくいが強い光で写り込む」性質を利用した実写トリックで、デジタル合成なしに印刷写真へそのまま反映させる方式とし、撮影後は携帯型フォトプリンタで即時プリントして手渡す。撮影係1名・演者1名・受付/プリント係1名の計3名体制とし、1組あたり撮影〜受け取りまで概ね3〜4分(印刷待ち含む)を想定する。

関所: 条件付きpass(暗めの撮影スペースでも足元は最低限の誘導灯・蓄光表示で躓き防止措置を行うこと/背景装飾材が照明機材近くにある場合は防炎品を使用すること/来店時に「撮影した写真を印刷してお渡しします」等の一般的な撮影同意掲示を行い、スマートフォン等デジタル経由で撮影した場合は印刷後にデータを速やかに削除すること) / 算盤: pass(演者衣装・背景装飾費は低額だが、印刷消耗品(フォトペーパー/インク、1枚あたり概算30〜100円)が主要原価となるため想定プリント枚数×単価で予算上限を事前に設定する運用が必要。撮影は複数人同時ポーズに対応でき1組4分弱で回せるため概算40〜60人/時を処理可能) / 近傍変種: 撮影直後にまずカメラ/画面上でプレビュー表示のみ行い、印刷は希望者のみ(または当日印刷枚数に上限を設定)とすることで、体験の核(写り込みの発見)を損なわずに印刷消耗品コストの上振れを予算内に抑制できる。
