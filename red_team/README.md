# red_team/ — 壺割り(型のレッドチーム)記録

- **目的**: rules.md v1.2 と pot_A 実走1ラウンドを証拠に、型の破れ目を叩く→解決を3ラウンド→納品。
- **納品物**: rules.md vNext / templates/(壺起動キット) / red_team/ 全記録 / DELIVERY.md(納品書)
- **不変の境界**: pot_A Stage4(代表選び)は舌の仕事のまま凍結。壺割りは壺の中の審美に触れない。攻撃対象は常に「型」。

## ラウンド構成
| Round | 内容 | レンズ | 成果 |
|---|---|---|---|
| R1 広域破壊 | 憲法と実走の破れ目を広く叩く | 封印/選別力学/運用/課信頼性 | findings + resolutions → v1.3 |
| R2 修正破壊+一般化 | R1の直しを再攻撃、本番規模へ外挿 | 修正の穴/一般化(軸あり・コード壺)/舌IF/停滞運用 | findings + resolutions → v1.4 |
| R3 閉鎖検証+検収 | 全クローズ確認・新鮮な目・納品検収 | doc-vs-diff監査/ブラインド再攻撃/検収 | findings + resolutions → v1.5 納品 |

## 記録の形
- `round<N>_<lens>.md` … 壺割り各機の所見(ID / 壊・歪・軋 / 根拠 / 攻撃シナリオ / 最小修正案)
- `round<N>_resolutions.md` … 壺師の裁定(採用/却下(by design理由)/保留(§14行き))と適用した差分の対応表
