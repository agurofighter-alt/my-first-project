# templates/ — 壺の起動キット(v1.3)

新しい壺はここから立てる。憲法は `rules.md`(必読)。

## 手順
1. `pot_X/` を切る(1壺=1ディレクトリ=1セッション)。
2. `shared_context_template.md` → `pot_X/shared_context.md`。**v1** として版番号を入れ、テーマ・与件・壺パラメータを埋める。センス軸は**舌が宣言した場合のみ**記入。
3. `state_template.md` → `pot_X/state.md`。壺パラメータ(バッチ規模・倍率・打ち切り基準)を **Stage0 で固定**。
4. Stage1〜:`task_template.md` から `task_XX.md` を**実ファイルで**作る(保存必須=実験の独立変数)。蟲師に渡すのは〈shared_context の中身+task の中身+出力フォーマット〉だけ。
5. 各Stage統合時(壺師):progress の**台帳検算** → **封印リンター**(`seal_linter.md`)→ `state.md` 更新(畳み台帳・リンター記録・実行モデル)。
6. Stage3収束 → 決勝候補リスト(光る順なし・前提構造・要人間確認欄付き)→ **舌**。

## 禁止事項の要約(詳細は rules.md v1.3)
- 連続量(回転・原価)の閾値割れで KILL しない(実数記録のみ)。
- からくり(生成)と客観課(判定)を同一エージェントに兼任させない。
- 重複KILL枠を自作の複製で埋めない。
- 安全・法規の主張は出典なしなら [未検証] タグ。人体接触/食品/火気/電気は「要人間確認」欄へ。
- 壺師出力に評価形容(地味/尖る/濃い/伸びしろ等)を書かない。
