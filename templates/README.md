# templates/ — 壺の起動キット(v1.5・起動の正典)

新しい壺は**必ずここから**立てる(§0/§10)。憲法= `rules.md`(必読)。壺クラスの語彙= `profiles/`。

## 手順
1. `pot_X/` を切る(1壺=1ディレクトリ=1セッション)。
2. **壺プロファイルを選ぶ**: `profiles/`(企画=kikaku/コード=code/専門=senmon/レイヤー2=layer2)。死因カテゴリ・「実質同じ」・課職掌・安全帳票領域はプロファイルが定義。
3. `shared_context_template.md` → `pot_X/shared_context.md`(**v1**)。Stage0宣言を埋める:テーマ/**治具or本番**/プロファイル/**与件(出所付き)**/**舌の帯域N**(既定6)/**★基準**(既定[未検証]≧2 or 単一障害点≧2)/バッチ規模・倍率・打ち切り基準/(軸あり壺のみ)軸と免罪語彙/(専門壺)壺内図書。
4. `state_template.md` → `pot_X/state.md`。Stage0宣言を**そのまま固定**(与件台帳を含む)。
5. Stage1〜: `task_template.md` から `task_XX.md` を**実ファイルで**作る(保存必須=実験の独立変数。毒の翻訳・例示は全文ここに)。蟲師に渡すのは〈shared_context+task+フォーマット〉だけ。
6. Stage3の課は**からくり(生成)→関所/算盤/橋渡し(からくり適用後を判定)**の順で別エージェント(兼任禁止)。算式併記義務。
7. **各Stage統合時**: 壺師が畳み(台帳記録)→ **目付**(壺師と別コンテキスト)がリンター走査・検算・台帳照合を実施し**検分書(metsuke_*.md)を自ら書く**(正本)。壺師は state.md に参照のみ転記。**検分書の無い統合出力は舌に渡せない**。
8. Stage3収束 → 決勝資料(乱数提示順・同格の欄・来歴表記)+**安全帳票(別紙・2区分)** → **舌**。応答は6種(§11)。生文を逐語記録。

## 禁止事項の要約(詳細は rules.md v1.5)
- 連続量の閾値割れでKILLしない(実数+算式のみ)。「与件」は壺の外から実在として与えられた制約に限る(需要目標の与件化禁止)。
- からくり(生成)と客観課(判定)の兼任禁止。重複KILL枠の自作複製埋め禁止。
- [未検証](検証不能な前提すべて——数値導出不能を含む)はKILL理由にならない。安全4領域+プロファイル拡張領域は安全帳票へ。
- 壺師出力に評価形容を書かない。舌の選択から選好を推測しない(舌前歴dedupのみ)。
- 監査(目付・リンター・★保護・全件再監査)を弱める方向の暫定改訂は不可(§15)。
